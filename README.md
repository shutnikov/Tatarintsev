# Weather Diary

Автор: Татаринцев Егор Дмитриевич

## Описание

Приложение "Weather Diary" позволяет вести дневник погоды: добавлять записи с указанием даты, температуры, описания и наличия осадков, просматривать их в таблице, фильтровать по дате и температуре, а также сохранять данные в JSON‑файл.

## Запуск приложения

1. Убедитесь, что у вас установлен Python 3.6+.
2. Запустите приложение.
