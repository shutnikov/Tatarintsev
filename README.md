# Expense Tracker

## Автор: Татаринцев Егор Дмитриевич

## Описание программы
Это простое приложение для отслеживания личных расходов. Вы можете добавлять расходы, фильтровать по дате и категории, а также сохранять данные в JSON-файл.

## Как использовать
1. Запустите программу.
2. Введите сумму, выберите категорию и дату.
3. Нажмите "Добавить расход".
4. Используйте фильтры для просмотра расходов за определенный период или категорию.
5. Данные автоматически сохраняются при закрытии программы и загружаются при запуске.

## Примеры использования
- Добавление расхода на еду 500 рублей 2024-04-01.
- Фильтр по категории "Транспорт".
- Просмотр расходов за апрель.
